OpenWrt · FOSS firmware

OpenWrt is a FOSS Linux distribution for embedded routers — not a brand UMRT certifies. Use the official Firmware Selector for your exact device and verify checksums/signatures per OpenWrt docs. Wrong image = brick risk. This hub links official OpenWrt project sites only.

Owner honesty

  • Exact device — pick the precise model/revision in the Firmware Selector (or Table of Hardware). Flashing the wrong image can brick the router.
  • Verify artifacts — check sha256sums / signatures against official OpenWrt download docs before any flash. Do not trust random re-packs.
  • Stable vs snapshot — production coaches usually want a stable release train, not daily snapshots, unless you are deliberately testing.
  • Not SpeedFusion — OpenWrt can do multi-WAN with packages; that is not Peplink Hot Failover / Bonding / Smoothing. Peplink path: /peplink/.
  • No OpenWrt “cert.” — FOSS project only. Field credentials on this site are Victron / weBoost / Peplink / Dometic / Starlink-install as listed in the footer — not an OpenWrt certification.

Vendor images vs upstream

Many travel routers (including some GL.iNet units) ship vendor OpenWrt-based firmware. That is not the same support path as flashing upstream OpenWrt from openwrt.org. Replacing vendor firmware with upstream is a different brick-risk and warranty path — see also /glinet/. We do not redistribute proprietary vendor “OpenWrt-derived” binaries on this hub.

Mirror honesty

Catalog policy is mirror-candidate, not an active mirror. Before any file lands under mirrors/: clear license, pinned upstream release tag, and SHA256 + upstream URL recorded in the catalog. No proprietary vendor .bin / “OpenWrt-derived” redistrib. Until pin + checksum exist: link only to official OpenWrt hosts. Full rules on Policy · ecosystem context on /foss/.

Field notes (link shelf, not a how-to dump)

  • Start at the Firmware Selector — do not guess filenames from memory or third-party blogs.
  • Confirm factory vs sysupgrade image type against OpenWrt install docs for that device.
  • Keep a recovery path (serial / TFTP / vendor recovery) in mind before first flash; Prefer Text if you are unsure.
  • Package feeds and LuCI versions track the release you flashed — match docs to that train.
  • Node-RED / Signal K on the LAN often sit behind an OpenWrt travel router — see /nodered/ and /foss/; we do not invent a supported-stack matrix.

Never

  • Cracked tools, unlocked firmware, or random “OpenWrt” re-packs from unofficial hosts.
  • Re-hosting proprietary vendor OpenWrt-derived binaries on this hub.
  • Flashing without verifying device identity and SHA256 against official OpenWrt artifacts.
  • Publishing checksums without a pinned upstream tag + SHA256 in the catalog.
  • Claiming OpenWrt certification or equating OpenWrt multi-WAN with Peplink SpeedFusion modes.
