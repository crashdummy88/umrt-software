When to use which Victron tool

Stand at the coach with Bluetooth in range → VictronConnect. GX already on the LAN or cellular and you are away from the rig → VRM. Deep MultiPlus / Quattro assistants → VEConfigure from Victron’s software hub, not a copied installer. Toolkit is a field helper (cable / LED reference). It does not commission a bank. If VictronConnect cannot see the product, the failure is usually VE.Direct, Bluetooth, or power — not a missing unofficial .swu.
