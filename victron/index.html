Firmware path (GX / Venus) — OEM only

When the GX has internet, use Victron’s online update flow. When it does not, pull images only from Victron Professional, the official release images feed, or Victron’s published GitHub project — then follow the Cerbo / Venus firmware manuals. Never flash a third-party .swu from a forum drive, and do not download firmware binaries from umrt-software.pages.dev (we link out; we do not host).
