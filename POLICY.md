# Mirror vs link-out policy

1. **Open source / FOSS** — Mirror only when the license allows redistribution (MIT, Apache-2.0, GPL with compliance, etc.). Keep `UPSTREAM` URL, version tag, and SHA256 in the catalog entry.
2. **Proprietary vendor firmware** — Never upload vendor `.swu` / `.bin` / `.zip` firmware to this repo or Pages. Link to the manufacturer’s official download portal.
3. **Mobile / desktop apps** — Link to Apple App Store, Google Play, or vendor desktop installers. No APK sideloads unless the vendor publishes them officially.
4. **No cracks, keygens, or “unlocked” firmware.**
5. **Copyright / DMCA** — If a rights holder objects to a mirror, remove the artifact and leave the upstream link.
