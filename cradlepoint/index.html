When to use NetCloud vs Peplink

Already on Cradlepoint

If the router is under an active NetCloud license, use Manager and Cradlepoint docs for that series. Firmware is a subscription workflow, not a file we can email you. Expired NetCloud is a licensing conversation with Cradlepoint, not a mirror on this hub.

New coach multi-WAN

We specify Peplink, name the SpeedFusion mode, and install on fused DC with Starlink and cellular as WANs. That is the product we stand behind. See Peplink software and connectivity installs.

Do not mix clouds

NetCloud is not InControl and not Sierra ALMS. Do not flash a Peplink image onto a Cradlepoint chassis or chase “unlocked NCOS” archives.
