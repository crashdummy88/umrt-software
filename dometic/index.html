Dometic · appliances & climate

Official Dometic apps, firmware & docs

Climate, refrigeration, and Dometic power gear show up on the same coaches we already diagnose for Victron and connectivity. This page maps Dometic’s own apps, in-app firmware path, support, and documents database — not a firmware mirror, not a third-party “unlock.”

Why this page exists

Owners text a fridge code or a rooftop A/C that will not pair. The next useful step is usually the official Dometic app for that family — or the documents database for the exact model sticker — not a blog firmware zip. If the appliance is dark because the inverter, converter, or lithium bank is down, start on Victron software.

Which app do you actually need?

Dometic is migrating Climate and Mobile Cooling into Dometic Power. Use Power first unless Dometic still lists your SKU on a legacy app. Store IDs below are official Dometic Group listings — we do not invent extra IDs.

Dometic Power (current)

Current app for Tempra / N-BUS power, FreshJet FJX/FJZ, FanTastic Breathe 3100, CFX3, and CFX5. Dometic’s published path for device firmware upgrades.

Apps hub · App Store id6648772769 · Play com.dometic.app

Mobile Cooling (legacy CFX2)

Still required for CFX2. CFX3 / CFX5 owners should move to Dometic Power per Dometic’s June 2026 migration note.

Migration · App Store id1495660690 · Play com.dometic.cfx3

Dometic Climate (legacy TwinBoost)

Still required for TwinBoost. FreshJet FJX / FanTastic Breathe 3100 should move to Dometic Power per Dometic’s March 2026 note. Area Camp Light app support is being dropped.

Apps hub · App Store id1660906196 · Play com.dometic.outdoor

Firmware path — OEM in-app only

Dometic does not publish a public .bin / .swu firmware shelf like Victron Professional. Compatible units get firmware inside the official app (Power, or Climate for leftover TwinBoost). Never flash a third-party Dometic package from a forum drive, and do not download firmware binaries from software.unitedmobilerv.com (we link out; we do not host).

When the official app is the right next step

Apps & pairing

Install the current store listing for the product family on the coach. Match the model sticker to Dometic’s supported-product list on the apps page.

Fault codes & manuals

Read the code on the unit, then search Dometic’s documents database for that series — not a generic blog table.

When the app is the wrong door

Gas appliances, sealed refrigeration, and rooftop climate are not a firmware flash. Text the model sticker, the code, and whether shore or inverter is up.
