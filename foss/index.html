FOSS

Official links

Open-source candidates for RV and light-marine field work: Signal K, OpenWrt, and Node-RED. This hub points at official project sites only. We integrate and install — we do not productize unvetted community flows, and we do not re-host proprietary vendor binaries.

What FOSS means on this hub

  • Link — default. Catalog cards and this page send you to the official project site, docs, GitHub, or package registry.
  • Mirror-candidate — a labeled possibility only. Before any file lands under mirrors/: clear license, pinned upstream release tag, and SHA256 + upstream URL recorded in the catalog.
  • Not a mirror yet — until pin + checksum exist, treat every FOSS card as link-only. See Policy.

Ecosystem overview

These three projects often sit together on coaches and light marine: Signal K for vessel/RV data, Node-RED for dashboards and bridges, OpenWrt under many travel routers. Start at the official homes — not random forks or re-packs.

  • Signal K — signalk.org · server: SignalK/signalk-server (Apache-2.0)
  • OpenWrt — openwrt.org · downloads: downloads.openwrt.org · source: openwrt/openwrt
  • Node-RED — nodered.org · docs: nodered.org/docs · dedicated hub: /nodered/ (also /node-red/)

Node-RED integrate/install only — no unvetted-flow productization. Match plugin versions to upstream docs; we do not invent a supported-stack matrix.

Mirror honesty

Catalog policy is mirror-candidate, not an active mirror. Before any mirrors/ file: clear license, pinned upstream release tag, SHA256 + upstream URL in catalog. No proprietary vendor .bin / .swu. Until then: link only. Full rules on Policy.

Never

  • Cracked tools, keygens, or unlocked firmware.
  • Re-hosting proprietary vendor binaries on this hub.
  • Shipping unvetted community Node-RED flows as a UMRT product.
  • Publishing checksums without a pinned upstream tag + SHA256.
  • Inventing certifications or a private “supported FOSS stack” matrix.
