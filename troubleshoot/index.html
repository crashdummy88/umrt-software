Symptom starters

No power

Coach or house loads dead? Start with shore / inverter / battery basics on the sales-site starter, then Text for a field diagnostic.

No water

Pump, tank, or winterize issues - use the sales-site starter, then Text if you need hands-on help.

Roof leak

Locate and dry first - sales-site starter walks the basics. Text for on-site tracing.

Generator won't start

Fuel, oil, and start interlocks - use the sales-site starter. Text for Onan / field work.

Starlink offline

Dish offline, searching, or app stuck - clear-sky installs; official Starlink support first, then Text for field work.

weBoost no boost

Booster on but no usable signal - outdoor RF required; AGC; no invent-from-zero. Official weBoost support + sales-site starter.

Peplink WAN flapping

WAN up/down or sticky failover - official Peplink firmware/InControl first. Field: bonding and/or failover (SpeedFusion).
