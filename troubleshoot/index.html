How to use this directory

Pick the symptom or the app. Each card is a field starter: official docs, then the checks we run before anyone flashes firmware. If the page still reads like a link shelf, the honesty is the point — we will not invent a procedure Victron / Peplink / weBoost / Starlink did not publish, and we will not host a .bin.

  • Power / water / roof / generator — physical first. Software hubs do not replace a dry bay or a fuel check.
  • Starlink offline — clear sky and power path before the app. Starlink installs only (never Certified).
  • weBoost no boost — outdoor RF required; AGC; no invent-from-zero. Credential: weBoost Authorized.
  • Peplink WAN flapping — name the SpeedFusion mode. Peplink Certified Associate. Missing peer ≠ “needs a firmware mirror.”
  • VictronConnect / GX / VRM — Bluetooth, network path, BMS gates. Victron Professional Certified Installer.
