Before you chase firmware

Most “software” failures we see on coaches are still physical or settings issues: phone Bluetooth permissions, GX Wi-Fi/Ethernet path, BMS allow-to-charge / cold-temperature charge inhibit, loose DC lugs (ripple), or a charger still on a lead-acid profile. Confirm the symptom in VictronConnect or on the GX display, then use Victron’s manuals. UMRT does not host .swu or .bin files.

VictronConnect won't find or won't pair

Bluetooth, VE.Direct, or VE.Smart link issues — work the phone and proximity first, then Victron’s docs and a store-fresh app build.

  1. Confirm Bluetooth is on; on many phones, location permission must be allowed for BLE scanning.
  2. Stand close to the product; metal bays and crowded 2.4 GHz kill discovery.
  3. Force-quit VictronConnect; toggle phone Bluetooth; retry. Try a second phone before condemning the dongle/product.
  4. For VE.Direct USB, confirm the interface and drivers per Victron docs — not a random cable claim.
  5. Update the app from the verified store listing below (not a sideload APK).

GX / Venus offline or won't update

Online update when the GX has internet; otherwise use Victron-published images from Professional or the release feed — never a third-party .swu.

  1. Confirm the GX has a working Ethernet/Wi-Fi path (captive portals at campgrounds break updates and VRM).
  2. Try online update per Victron’s firmware-updating doc.
  3. If offline, pull the correct image only from Victron Professional or the official release images feed; follow the Cerbo firmware manual.
  4. Do not flash files emailed by strangers or mirrored on UMRT — we link out only.

VRM portal or app blank / not logging

Confirm the GX is online and the site is registered, then use Victron's VRM docs and verified official apps.

  1. On the GX: confirm internet and VRM logging / two-way communication status.
  2. On the portal: confirm you are viewing the correct installation and time range.
  3. Reinstall the mobile app only from the store IDs below — wrong VRM listings exist online.

“Not charging” that looks like an app bug

If VictronConnect shows an MPPT or Multi awake but charge current is ~0, check physical and BMS gates before firmware:

  • LiFePO4 cold-charge inhibit near/below freezing unless heated/gated — warm cells / read BMS allow-to-charge. (Example only: many BMS charge-inhibit around 0 °C / 32 °F — confirm your battery/BMS manual; some heated packs differ. No universal cutoff.)
  • True LiFePO4 profile (or Victron commissioned voltages) — dumb converters are not “drop-in.”
  • Chassis path needs Orion-class DC-DC (e.g. Orion-Tr Smart — illustrative class example, not a must-buy SKU / partner badge) — unprotected alternators are a hardware problem, not an app toggle.
  • Loose DC lugs / undersized cable → ripple alarms; retorque and verify Class-T (or mfr-required) at the Li bank.
