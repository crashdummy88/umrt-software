Mirror honesty

Catalog policy is mirror-candidate, not an active mirror. Before any mirrors/ file: clear license, pinned upstream release tag, SHA256 + upstream URL in catalog. No proprietary vendor .bin / .swu. Until then: link only. See Policy.

Field checklist

  • Editor will not open — confirm process and host:port per getting-started.
  • Missing nodes — install from official palette / npm; prefer flows.nodered.org or project GitHub.
  • Dashboard blank on LAN — check bind address and dashboard package docs for your version.
  • Signal K data missing — verify Signal K is up and nodes match upstream Signal K docs.
  • After an update — export flows first; read GitHub release notes before upgrading.

Never

  • Cracked tools, keygens, or unlocked firmware.
  • Re-hosting proprietary vendor binaries on this hub.
  • Claiming a proprietary UMRT Node-RED product or invented certifications.
  • Publishing checksums without a pinned upstream tag + SHA256.
