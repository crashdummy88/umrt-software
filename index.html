Which software do you actually need?

Most coach problems are not “download the newest file.” They are the wrong app for the product, a GX that never joined VRM, a Peplink mode that is failover while someone called it bonding, or a booster app that cannot invent outdoor RF. Start with the tool that matches the hardware.

VictronConnect

Day-to-day configuration over Bluetooth or VE.Direct: MultiPlus-class inverters, SmartSolar MPPT, Orion DC-DC, SmartShunt. Use this at the coach. Use VRM when a GX is already online and you are away from the rig.

Victron software · GX / VRM troubleshoot

Venus OS / GX + VRM

Cerbo, Ekrano, and other GX devices run Venus OS. Update from Victron’s online flow when the GX has internet; otherwise pull images only from Victron Professional or the published release feed. VRM is remote monitoring after the GX is commissioned — not a substitute for VictronConnect at the panel.

Firmware path · GX / VRM troubleshoot

Peplink firmware + InControl

Flash firmware from Peplink only. InControl 2 is the cloud desk. Name the SpeedFusion mode: local outbound failover, Hot Failover, Bonding, or Smoothing are different products. Entry chassis may need PrimeCare before those modes unlock.

Peplink software · WAN flapping

Starlink app

Account, obstruction, stow, and reboot live in the official app. Residential is a fixed address. Roam is travel. Bypass mode is how a Peplink (or other router) takes WAN — not a firmware we host. Clear sky still beats a clever mount under trees.

Starlink software · Dish offline

weBoost app + support

The app helps aim and confirm before/after readings. It does not create outdoor RF. Automatic gain control already manages output — we do not sell “tune gain.” If outdoor signal is absent, software will not invent bars.

weBoost software · No boost

Node-RED · Signal K · OpenWrt

Open-source dashboards and travel-router firmware. We integrate and install; we do not productize unvetted community flows or re-host vendor “OpenWrt-derived” images. Wrong OpenWrt image can brick the router.

Download policy

  • Link — proprietary firmware and apps from official manufacturer or store sources only.
  • Mirror — FOSS only, after a pinned upstream tag, checksum, and recorded URL. See Policy.
  • Never — cracked tools, unlocked firmware, or re-hosted vendor .bin / .swu packages.
  • Credentials (text only) — Victron Professional Certified Installer · weBoost Authorized Installer · Peplink Certified Associate · Dometic Professional Certified · Starlink install capability (no invented Starlink cert).
