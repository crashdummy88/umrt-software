Starlink — Official Links

Official Starlink app, support, plans, hardware specs, bypass mode, and accessories. Clear-sky installs only. Install capability — not a Starlink Certified title.

Start at the manufacturer portal: starlink.com/support

Plans honesty: Residential = fixed address (no roam / no in-motion). Roam = RV / travel (pause/standby; in-motion in select areas). /rv redirects to Roam — not a separate SKU. Compare on service-plans.

Install honesty (accessories): prefer official mounts/cables and kit install PDFs over clone hardware. Seal roof penetrations; protect cable runs; size DC/inverter for the kit (Mini vs Flat HP / HP draw differs a lot — see specs PDFs). Clear sky still beats a fancy mount under trees.

Hardware: official specifications + Mini / Flat High Performance / High Performance PDFs in the catalog cards below.

Third-party router: use official bypass mode with Peplink for bonding and/or failover (SpeedFusion) — never re-host proprietary firmware.

Policy: manufacturer / store links only for proprietary software. FOSS mirrors require a clear license — see Policy.
