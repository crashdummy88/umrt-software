## What this is
A developer-style hub for **firmware, software, and app links** used on RV / mobile power & connectivity installs:

| Kind | Policy |
|------|--------|
| **Open source** | We may **mirror** release artifacts we have rights to redistribute (license must allow it). Prefer checksums + upstream link. |
| **Vendor / proprietary** | **Link only** to official manufacturer download / app-store pages. Do **not** host closed firmware or cracked tools. |
| **Apps** | Link to official iOS / Android / desktop store pages (Victron Connect, Dometic, Peplink InControl, Starlink, etc.). |
